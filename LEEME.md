# Mis Devocionales — APK

GitHub construye la APK sola cada vez que subes cambios.
Descárgala en **Releases** (archivo `MisDevocionales.apk`).

- `app/src/main/assets/index.html` → la app completa.
- `app/src/main/assets/*.json` → Biblia RV1909 y palabras originales (Strong).
- `app/src/main/assets/cuentos/` → ilustraciones de los cuentos.
- `MainActivity.java` → voz del celular para 🔊 Escuchar, copiar, abrir enlaces y botón atrás.
